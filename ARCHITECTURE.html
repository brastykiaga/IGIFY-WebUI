Key design principles:
  • Offline-first: Public content and locally stored services remain useful without internet.
  • One provincial deployment: Each installation serves its own province/state community.
  • Independent services: New services register through the Service Integration Layer without frontend redesign.
  • Backend enforcement: Authentication, authorisation, and validation happen server-side — never in the frontend.
  • Production: Docker + NGINX serving static dist/ output. Vite dev server is for development only.
